# 粗拉片：用有限阅读支持下一步判断

状态：2026-10-14 提案，未实施、未实测，尚不代表用户已确认具体字段或预算。

## 目标与判断

用户明确希望在精细拉片之外增加粗拉片，快速获取关键信息。本轮先回答粗拉片应该长什么样。“快速出一些内容”暂按快速交付可读分析理解，尚不能据此认定需要直接代写新视频脚本。

粗拉片要让读者迅速回答：这条片讲了什么，靠什么顺序讲明白，哪一处值得回看或借鉴。它的价值来自减少获取和阅读关键内容的成本；完整重建所有信息不是本流程的完成条件。若报告虽然短，却省掉改变结论的条件、结果或反转，便没有完成任务。

现行 Builder 要两轮构建 probe/captureProtocol 与 reconstruction，完整还原知识、逐句归属，并生成三个完整 builderLenses；Reviewer 又独立核对材料并提出修订。由这些合同可以判断工作范围较大，但未读取计时实验，不能断言具体环节占用了多少时间。只删复核或压缩最终字数仍保留主要工作量。

## 提议的阅读成果

一份可在约一至两分钟内读完的图文速览（阅读体验目标，待实测）：

1. **一句话看懂。** 讲什么、面向谁、给出什么观点/结果/感受；不存在的维度不硬填。
2. **核心内容。** 通常三至五条，保留具体结论、必要条件和最有信息量的例子。区分作者说法、画面展示与分析判断。
3. **大段结构。** 通常三至六段，沿时间说明“发生了什么 → 这一段在整体里起什么作用”。按本片组织，不强塞钩子—冲突—反转模板。
4. **最值得借鉴的一至三处。** 写清具体做法、相关时间点、为什么可能有用及适用条件。画面或剪辑只有确有辨识度时展开，不凑齐术语栏目。分析上的效果解释不冒充观众数据或爆款因果。
5. **回看与边界。** 少量关键时间点/帧，以及会影响使用结果的未确认项。必要时明确某段值得精看及原因；不默认每片都需升级。

首屏包含一句话、核心内容和最有信息量的画面；结构与借鉴点向下连续阅读。证据靠近主张，点时间可返回原片。小型结论无需每句配图，不能用无关美图替代依据。以上数量是默认写作预算，不能为了凑数发明内容，也不能为了限数删掉颠覆主旨的信息。

## 最小工作流

**复用来源与素材 → 通读可用文字、抽样浏览全片画面 → 只补影响核心判断的疑点 → 直接写速览 → 机械校验交付。**

读取原帖、可用字幕/转写与覆盖全时间范围的代表画面；覆盖时间范围不等于看尽每个事件。重点观察开头、内容转折和结尾，不只看开头猜全片。无口播或信息主要在动作中的视频需读取对应动作短片段/序列，不能退化成字幕摘要；没有可用音频观察时不评价音乐音效。

模型在同一工作上下文中选择并解释关键内容，不必先交付一套完整探针、捕捉协议、逐句覆盖矩阵和三篇长文。只有某个疑点可能改变主旨、关键条件、结果或核心手法时补看；默认一轮集中补看，预算仍无法解决时缩小主张并保留未知。素材不足以支撑核心内容时，清楚交付部分速览及缺口，不能标完成的全片理解。

默认不运行独立 Reviewer 与自动修订循环。宿主仍检查来源绑定、时间范围和证据引用。机械校验通过不意味着分析已独立验证。精细分析继续保留；同一素材的粗、精结果各有明确身份，复用冻结媒体和已准备证据，但粗分析不能伪装成精细 reconstruction 或覆盖现有主报告。

## 验证与取舍

先用三类已有短片试跑：口播讲解、视觉/操作主导、故事或观点推进。读者读完应能复述主旨与关键条件，按时间找到核心证据，并指出一个具体可借鉴的做法。对照原片检查是否漏掉改变结论的信息；精细报告仅作辅助对照，不作唯一真值。

分别记录素材准备耗时、分析耗时、补看次数和阅读耗时。以这些证据选择预算；当前不承诺“几分钟完成”或固定加速倍数。粗拉片若需要不断追加细节才能作基本判断，应修正关键内容选择规则；只有特定局部超出职责时再精看该段。

待确认的主要分叉是下游用途：理解/筛片，还是立即改写创作。后者可以消费速览再生成选题或脚本草案，但属于另一个产出目的，不应让每次粗拉片都自动承担。
