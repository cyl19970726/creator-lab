# B3 标准卡 v3

B3 只做一件事：**成品把 B2 定稿讲出来，而且在手机上看得清。**
成品检查者必须实际打开快照图逐格看；每条给 ok / weak / fail 和一句理由，并指出是第几段。任何 fail 即 revise。

| id | 标准 | fail 的样子 |
|---|---|---|
| V1 | **开头 3 秒的画面就是钩子。** 第一段的数字或矛盾占满画面主位。 | 开头是标题卡、logo 或空背景。 |
| V2 | **每段一个主画面，而且够大。** 主视觉占画面中部至少四成高度，手机上读得清；屏幕文字不超过两行。 | 主体缩在顶部或角落、中间大片留白；或一帧塞满小字、多个图表并列。 |
| V3 | **静音也看得懂。** 关掉声音只看这一帧，观众能说出这一段在讲什么；这一段的核心动作或对比（例如"只判对错、不给示范"）被画出来，而不只是一行标题或一个数字。 | 画面只是标题卡或数字卡，这一段真正的意思只在口播里；B2 写的画面意图没兑现。 |
| V4 | **版式安全区。** 内容在 y≤1340；字幕带 y1390–1570 独占；右侧 x≥930、y640–1600 避让平台按钮。 | 主图压在字幕带里，或文字被右侧按钮区挡住。 |
| V5 | **没有渲染事故。** 无重叠、溢出、截断、空白帧、乱码。 | 文字互相压住，元素出屏，某格全黑。 |
| V6 | **屏幕上的事实和 B2 定稿一致。** 数字、名称和"论文报告/官方说明"标注都对。 | 数字写错，或丢了来源标注。 |
| V7 | **风格一致，但段落之间一眼可分。** 账号的深色底与青/珊瑚强调；贯穿图只完整展开一次；不同段落不用同一种版式；页脚编号与总段数一致。 | 每帧一种风格；或两段都是"三张竖排卡片"几乎一样；或页脚写着 01/02 而全片有 8 段。 |
