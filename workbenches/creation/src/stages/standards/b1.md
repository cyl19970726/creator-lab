# B1 标准卡 v6

B1 只做一件事：**选对这一篇要回答的问题，并确认我们答得上、答得好。**
挑战者逐条检查；每条给 ok / weak / fail 和一句理由。任何一条 fail 即 revise。

| id | 标准 | fail 的样子 |
|---|---|---|
| S1 | **问题来自观众，不来自材料。** 核心问题能用目标观众的原话说出来，并且是他们真会好奇的。 | 问题是"X 的流水线是怎样的"这类材料目录；观众不会这样问。 |
| S2 | **有一个"原来如此"的答案。** 一句话答案必须说出**化解矛盾的那个机制**——观众听完能说"原来是这样"。检验：把答案讲给持原直觉的人（例如"老师得比学生强"），他的直觉会被哪句话推翻？ | 答案只是"学生本来就有能力""它提供线索""很复杂"这类不解释**为什么能超过**的说法；或只罗列组件名。 |
| S3 | **答案被材料撑住。** 节拍里实际说出的每句话都能指向具体材料；缺口要么补上，要么缩小承诺。观众问题的字面前提可以被答案纠正，纠正不需要额外证明那个错误前提。 | 节拍没有来源；或为了迁就材料把核心问题换掉了；或反过来，因为无法证明观众的字面前提而把一个已经化解矛盾的答案退成"暂缓"。 |
| S4 | **开头有钩子。** 10 秒内抛出观众的矛盾或一个反直觉的事实。 | 开头是背景介绍、免责声明或术语。 |
| S5 | **账号视角成立。** Token 经济猫讲技术，也讲"钱和算力花在哪、为什么"。 | 与账号无关的泛科普；或硬加没有依据的成本排名。 |
| S6 | **承诺大小合适，一个节拍只讲一个点。** 3–5 个节拍；每个节拍只说一个机制或一个证据，最多两句、新出现的专有名词不超过两个。 | 想讲完整份技术报告；或一个节拍里同时塞"轨迹 + 核验 + 人工标注 + 多教师蒸馏"这样四五个概念——B2 再怎么改观众也会在这里跟丢。 |
| S7 | **严谨靠准确，不靠免责。** 节拍里的限定语（"报告没有给出…""不能证明…""仅代表…"）全篇最多两处，挑战时逐条数出来；证据边界写进"最大风险"和"待确认"，不写进节拍。 | 三处以上限定语，或每个节拍都挂一句"没有证明…"。 |
| S8 | **写清不讲什么。** 明确放弃的方向，防止 B2 把它们加回来。 | 没有取舍，或取舍只是重复免责。 |
| S9 | **创作者点名的案例要扛起答案。** 选题里指定的材料或案例（例如"用 Kimi/GLM 的训练流水线讲"）是题目的一部分：一句话答案的机制要能在这些案例里看到。材料答不上时先找连接点；找不到就停下来问创作者，不能换材料，也不能让别的材料扛答案、指定案例只当背景。 | 指定案例被写进"不讲什么"；或答案的机制来自别的材料，指定案例只在后面讲"反馈怎么流动"之类的配角内容。 |
| S10 | **一个案例只承担一个节拍。** 多个案例时，每个案例放在一个节拍里、说明一件事；不要把同一案例拆到多个节拍穿插出现。 | 案例 A 出现在节拍 1 和 4、案例 B 出现在节拍 2、3、4——B2 怎么改观众都分不清谁说明了什么。 |

## 用户审阅记录（每次审阅后追加；这是 agent 将来替代用户审阅的依据）

### 2026-09-30 · Kimi/GLM「弱模型怎么训出强模型」· 第 1 轮 · 代理审阅（Claude 代创作者）
挑战者判 pass，审阅判 **revise**——不一致，以下三条是挑战者漏掉的：
1. **放弃了创作者指定的案例（S9）。** 内容决定把 Kimi/GLM 流水线写进"不讲什么"，整篇改讲 OpenAI 弱到强论文。正确做法是找连接点：在强化学习后训练里，"老师"不是一个更强的模型，而是判卷的验证器和环境；Kimi/GLM 的材料讲的正是这套"让模型大量尝试、再判对错、送回训练"的系统。
2. **一句话答案是泄气式的（S2）。** "学生原本就有预训练能力"是在说"其实没那么神奇"。要给出机制上的"原来如此"：判卷比做题容易，所以不会做题的老师也能教出更会做题的学生。
3. **账号视角要落到具体的钱上（S5）。** 本题现成的经济角度：后训练的投入越来越多花在"让模型试得起、试得多、判得准"——沙箱、长任务续跑、异步数据流，这些正是 Kimi/GLM 花工程力气的地方；GLM-5.3 与 5.2 同一底座、提升全部来自后训练，是最直接的证据。
