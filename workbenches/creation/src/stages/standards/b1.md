# B1 标准卡 v2

B1 只做一件事：**选对这一篇要回答的问题，并确认我们答得上、答得好。**
挑战者逐条检查；每条给 ok / weak / fail 和一句理由。任何一条 fail 即 revise。

| id | 标准 | fail 的样子 |
|---|---|---|
| S1 | **问题来自观众，不来自材料。** 核心问题能用目标观众的原话说出来，并且是他们真会好奇的。 | 问题是"X 的流水线是怎样的"这类材料目录；观众不会这样问。 |
| S2 | **有一个"原来如此"的答案。** 一句话答案能化解观众的直觉矛盾，而不是一串机制名。 | 一句话答案是"由 A、B、C 三个组件组成"；或答案只是"很复杂"。 |
| S3 | **答案被材料撑住。** 每个节拍都能指向具体材料；缺口要么补上，要么缩小承诺。不能偷换成材料更好答的问题。 | 节拍没有来源；或为了迁就材料把核心问题换掉了。 |
| S4 | **开头有钩子。** 10 秒内抛出观众的矛盾或一个反直觉的事实。 | 开头是背景介绍、免责声明或术语。 |
| S5 | **账号视角成立。** Token 经济猫讲技术，也讲"钱和算力花在哪、为什么"。 | 与账号无关的泛科普；或硬加没有依据的成本排名。 |
| S6 | **承诺大小合适。** 选定的载体和时长里讲得完；节拍 3–5 个。 | 想讲完整份技术报告；节拍超过 6 个。 |
| S7 | **严谨靠准确，不靠免责。** 限定只放在真正会误导的地方，一篇最多两处。 | 每个节拍都挂"不能证明…""仅代表厂商…"，钩子被免责淹没。 |
| S8 | **写清不讲什么。** 明确放弃的方向，防止 B2 把它们加回来。 | 没有取舍，或取舍只是重复免责。 |
| S9 | **创作者点名的案例不能丢。** 选题里指定的材料或案例（例如"用 Kimi/GLM 的训练流水线讲"）是题目的一部分。材料答不上核心问题时，先找它和问题的连接点；找不到就停下来问创作者，不能换成别的材料。 | 把创作者指定的案例写进"不讲什么"，改用更好讲的外部材料。 |

### 2026-09-30 · Kimi/GLM「弱模型怎么训出强模型」· 第 1 轮 · 代理审阅（Claude 代创作者）
挑战者判 pass，审阅判 **revise**——不一致，以下三条是挑战者漏掉的：
1. **放弃了创作者指定的案例（S9）。** 内容决定把 Kimi/GLM 流水线写进"不讲什么"，整篇改讲 OpenAI 弱到强论文。正确做法是找连接点：在强化学习后训练里，"老师"不是一个更强的模型，而是判卷的验证器和环境；Kimi/GLM 的材料讲的正是这套"让模型大量尝试、再判对错、送回训练"的系统。
2. **一句话答案是泄气式的（S2）。** "学生原本就有预训练能力"是在说"其实没那么神奇"。要给出机制上的"原来如此"：判卷比做题容易，所以不会做题的老师也能教出更会做题的学生。
3. **账号视角要落到具体的钱上（S5）。** 本题现成的经济角度：后训练的投入越来越多花在"让模型试得起、试得多、判得准"——沙箱、长任务续跑、异步数据流，这些正是 Kimi/GLM 花工程力气的地方；GLM-5.3 与 5.2 同一底座、提升全部来自后训练，是最直接的证据。
