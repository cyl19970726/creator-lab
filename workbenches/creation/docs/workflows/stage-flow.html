  1. 怎么交接。你在某个阶段判通过（pnpm stage:accept），程序就从这次运行自己的产出和冻结输入生成下一版档案（brief/v<n>.json）；B2、B3 用 "briefFrom" 取最新档案，并把它原样冻结进自己的输入，可复现。
  2. B2 现在拿到了观众问题（原话、直觉、矛盾）、账号现状与参照作品教训、选题判断、"写给 B2 的话"（你的意见 + B1 挑战者没解决的"偏弱"项）。
  3. B3 现在拿到了核心问题、一句话答案、钩子、各节拍的画面想法，以及"写给 B3 的话"（你的意见 + B2 主编总结与偏弱项 + 事实核查的改法）。成品检查做静音测试时对照一句话答案。
  4. 仍然故意不给：冷读者只看观众看得到的东西；B3 不拿原始研究材料；B2 拿到的是 B1 已定的决定，不是重新选题的自由。
