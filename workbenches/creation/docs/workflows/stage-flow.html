B1 · B2 · B3：每个角色拿到了什么、产出了什么

先说结论：B2、B3 确实没拿到一部分核心输入，问题主要出在阶段之间的交接。
  1. 交接是手工拼的。B1→B2、B2→B3 的输入，是主 agent 在会话里用临时脚本拼出来的，不是 workflow 的一步。换个人跑，带过去的字段就可能不同。这和之前"主 agent 在 workflow 外干活"是同一类问题。
  2. B2 没拿到"观众问题"和"参照作品的教训"。作者不知道观众原来的直觉是什么，也不知道 EP01 的"2 分 46 秒太长、多数人 30 秒内离开"。b2-v6 的开头因此写成了概念题，没有具体事实。
  3. B3 只拿到稿子。B1 的一句话答案和钩子意图、B2 主编写给制作的建议（例如"把'同一基础模型'简化成画面上的同一起点"）、你的审阅意见，都在交接时丢了。
  4. 但也不是每个角色都该拿全部材料。冷读者必须隔离；B3 不需要原始研究材料；B2 不该拿到"可以重新选题"的自由。原则是：上游定下的决定 + 这个阶段需要的上下文 + 上游留给它的话。
拿到了应该拿到但没拿到故意不给产出✋ 当前靠主 agent 手工拼接
