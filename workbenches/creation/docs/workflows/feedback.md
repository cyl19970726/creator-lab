# 发布后互动与效果回顾

用户2026-09-08确认：每个平台作品发布后48小时内每小时查看并回复评论，满48小时采集数据并Review。以下为执行协议；工作台界面尚未实现，自动化登记不等于平台采集/回复已经成功。

## 1. 生命周期与调度

统一小时巡检任务读取data/post-publish/index.json。每个平台独立登记account_id、content_id、url、published_at（含时区）、report_version、video_version、expectation_path、state_path、enabled。只能登记真实核验的已发布作品；submitted/reviewing不可当起点，未知发布时间先核实。旧作品不因新登记重启48小时互动。

0≤作品年龄<48h：首轮在发布后下一次小时巡检；每次检查新增评论/楼中楼，有值得回复的再回复，不是每条机械回。48h≤年龄：停止小时自动回复，执行一次48h数据快照与Review；之后默认72h、96h各补一次定量快照与趋势复验，96h完成后关闭本轮。后两次是本阶段默认执行选择，用户可调整；无需无限每日巡检。调度延迟按真实采集时间标记，不伪造精确48h样本；错过多个节点时一次当前快照并标明缺失历史，不制造多个历史样本。

空登记表不访问无关账号、不猜测作品、不发消息。每轮记录last_attempt_at、last_success_at、next_due_at、实际阶段、错误和产物定位；同一作品已有执行中实例不并发处理。scheduler只负责唤醒；平台作品/评论与原生执行记录证明实际结果。

## 2. 评论互动

用户已授权本流程在登记作品的评论区回复。发前核账号、作品、评论及是否已有本账号回复；优先具体问题、理解障碍、有效纠错。基于已审报告和实际证据简洁回答，具体不确定处明说；不编部署实测、不承诺收益/购买结果、不索要隐私、不自动推销或私信、不争辩刷屏。

事实争议需额外研究时登记问题，可给有依据的限定说明；不能为了每小时完成任务强答。重大错误回研究Reviewer，不自行改原视频或删除评论。登录/验证或平台拒绝时停止写操作，记录待处理，不绕过限制。

以平台＋账号＋作品ID＋评论ID去重。发前保存pending意图，发后核实际回复ID/截图；提交不确定时只读核对，不盲重发。记录sent/confirmed/uncertain/deferred，不把工具调用当发送成功。48h后的评论仍可采集用于Review，自动回复需另行范围决定。

## 3. 发布前写预期，发布后看证据

expectation.md绑定标题/封面/脚本/成片版本，逐项写：设计元素、旧视频或本次时间区间、希望观众认出/理解/获得什么、首次兑现时刻、预期可观察信号、比较基线、可能反证、观察窗口。不强制编数值目标；已有数据才建立可比基线。未在发布前记录则标“事后重建假设”，不得称原先预期。

示例：0–10秒想让观众认出“容量够并不代表部署快”，并看到一个实际差异；证据可来自同期2秒跳出、早段留存和评论理解。只有总体完播率时，不足以定位到这一句；评论未提某事也不能证明所有人理解了。

## 4. 48小时Review及72/96小时补测

按抖音、小红书等平台原字段采集：播放/曝光、有效观看、完播、2秒跳出、平均观看、可用留存曲线、点赞、收藏、分享、关注及评论。不可用字段记unavailable，记录统计定义、窗口、分母、时间、作品版本和原始截图/导出。各平台同名字段也核定义，不直接合并；后台延迟与约数注明。

独立反馈Agent整理，video-editorial-review的learning模式独立审。输出设计预期→实际观测→支持/相反/不足判断→替代解释→下一版最小变化。区分“数据相关”和因果；流量来源、曝光规模、题材、时长、美术同时变化不能归因某个hook。没有逐秒曲线不捏造掉点，没有对照不说证明某元素有效。

反馈进入三条线：事实/原理缺口回research；理解/结构/兑现问题回research-to-video；题目需求进入后续选题。Review本身不授权重做全片或发布新作；可继续已获授权的修复。72/96小时补测更新原判断的置信与限制，不为数据波动反复改结论。

## 5. 工作台显示

每个平台作品显示发布时刻、48h截止、下次检查、最后成功检查、已核回复/待答/发送不确定、数据新鲜度、48/72/96h Review状态。Review页并排展示预期时间轴、实际指标/曲线、代表评论、判读和修改建议。数据缺失不画成0，尚未采集不显示已完成。

“需要用户”仅列账号接管、真实范围取舍、重大事实风险/必要授权；正常回复与常规Review入日志。无变化不打扰用户；发现可行动问题、完成阶段Review或实际阻塞才通知。内部原始评论与账号信息不打包进公开报告。
