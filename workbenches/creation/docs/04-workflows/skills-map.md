# 创作方法入口

完整方法正本在本工作台`.agents/skills`：research-to-video、video-evidence-brief、video-content-architecture、video-hook-opening、video-title-cover、video-production-handoff、video-editorial-review、video-publish-closeout、video-learning-loop。

核心阶段为B1内容定位、B2表达设计、B3制作与视听复验、C1平台交付、C2反馈。研究实现由兄弟research工作台负责，此处只读已有输入。方法中的历史账号/作品状态和外发授权不会随迁移继承；本轮以真实清单与决定为准。
