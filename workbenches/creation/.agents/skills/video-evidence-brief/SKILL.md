# Video Evidence Brief

先读[版本合同](../research-to-video/references/contracts.md)。输出精简证据底稿，保留原报告作为深度资料，不把整份报告摘要当脚本。

1. 从用户原话提取要帮助谁做什么判断，记录已确认主题及报告版本。现有文章若已完成叙述组织，直接索引复用。
2. 为影响开头、比较、结论的主张分配ID。逐项列：来源定位与日期、原始记录/作者主张/计算/假设、适用对象、允许措辞、不能推出什么。
3. 数字保留单位、分母、生成/观测条件和公式。路线比较区分配置、精度、后端、时长、成本范围；“最快运行”“最快回本”“生产验证最充分”不是一个排序。
4. 收益内容区分官方价锚、真实成交、满负载、合格率、全部售出、计入成本。算术成立不等于经营结果。未定价的行不填真实回本或年利润；误算演示独立命名。
5. 研究图只继承有依据的对象和关系，不继承未经核实的绝对措辞。用户技术解释也按主张核对；修正事实不必把完整纠错课程塞给观众。
6. 给来源缺口具体处置：补材料、收窄措辞、删除主张。只补本片关键缺口。涉及当前规格、行情或平台规则时验证当前一手来源；历史测算注明日期，不冒充今天数据。

输出`evidence-brief.md`和必要的原始数字表。每条关键事实能追溯，未知可见；提交`video-editorial-review` evidence模式。不得用模拟截图证明真实外部传播，不用用户认可代替事实证据。
